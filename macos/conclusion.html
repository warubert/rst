RST instalado

Abra o RST pelo Launchpad ou pela pasta escolhida na instalação, ou digite rst no Terminal.

Para criar legendas com o Whisper

O RST precisa do FFmpeg e do OpenAI Whisper instalados e disponíveis no PATH:

brew install ffmpeg
pip install -U openai-whisper

Sem eles, a opção de criar legendas com o Whisper fica indisponível. As demais funções continuam funcionando.

Desinstalar

No Terminal: rst-uninstall
